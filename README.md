# AI Engineer Workshop

This repository contains a workshop for AI Engineering with practical implementations of various AI capabilities using AWS Bedrock and Claude models.

## Prerequisites

Before starting the workshop, ensure you have the following installed:

- Node.js
- Git
- An IDE of your choice (e.g., VSCode, Atom, WebStorm)

## Project Overview

This workshop uses a starter project with:
- Plain JavaScript, HTML, and CSS (no frameworks like Angular or React)
- Express.js backend
- Basic UI elements pre-built
