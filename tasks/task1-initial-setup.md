# Task 1: Initial Setup

## Overview

This task focuses on setting up the initial project environment by cloning the repository and running the application to ensure everything is working correctly.

## Instructions

### 1. Clone the GitHub Repository

```bash
git clone https://github.com/ranjanmadhu/ai-workshop.git
```

### 2. Navigate to the Project Directory

```bash
cd ai-workshop
```

### 3. Install Dependencies

```bash
npm i
```

### 4. Run the Project

```bash
npm run start
```

### 5. Verify Setup

Open your browser and navigate to http://localhost:3000. You should see the initial UI loaded.

## What You'll Learn

- Basic project setup
- Using npm for package management
- Starting an Express server with node.js
